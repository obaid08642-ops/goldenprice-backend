# Premium icon set: prompts for an image generator

Goal: one consistent set of soft 3D "clay" illustrations (like a Pixar-style render), one per item, so every page shows its own picture instead of emoji.

## Style (paste at the end of every prompt)
`cute 3D clay render icon, soft pastel colors, smooth rounded shapes, soft studio lighting, gentle soft shadow underneath, premium app illustration, centered single object, plain solid light background, no text, no letters, no logo, high detail, 1:1`

Use the same generator, same style line and the same seed/style reference for the whole set. Export 1024x1024 PNG. Ask the tool to remove the background (or I do it), name each file with the id below, and put them in a folder to upload.
